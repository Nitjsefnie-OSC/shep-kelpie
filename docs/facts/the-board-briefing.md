# The board briefing

- The briefing's measured shape (2026-10-05, on 33 decision points from shep and shep-kelpie and one scripted day of 40 wakes): every PM arm avoided more real conflicts than the board rule (9 to 12 of 11 to 15, against 4 of 15), since most ready issues name no file and the rule cannot see a conflict. A briefed PM cost about half the units a wake of one that ran git and gh itself. A board for a day on shep-kelpie ran 17k to 30k characters, most of it the ready issues' bodies.
- `git merge-tree --write-tree --name-only --no-messages -z <a> <b>` on git 2.50.1 prints the merged tree's id and then each conflicted file's name, each ended by a NUL, and exits 1 when anything conflicts and 0 when nothing does. A file both sides change the same way does not conflict. Given a commit it cannot find, it also exits 1, with nothing on stdout and `not something we can merge` on stderr, so the board reads a conflict only when the first name is a tree id. Measured 2026-10-05 on scratch repos.
